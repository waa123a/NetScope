# 新模型启动提示词

将下面整段发给接手项目的模型，并确保四个状态文件在同一工作目录。

```text
你将接手这个项目。先完整阅读：
- PROJECT.md
- ARCHITECTURE.md
- PROGRESS.md
- TEST_LOG.md

不要修改任何代码。用 10 行以内复述：
1. 项目目标与非目标；
2. 架构边界与关键契约；
3. 已完成内容和验证方式；
4. 当前阻塞；
5. 下一步任务。

然后指出文档中互相矛盾、缺失或过时的信息。
确认后，只执行 PROGRESS.md 中“下一步”的第一项，不要扩大范围。

执行要求：
- 动手前先给计划和验收标准；
- 缺陷先给根因假设和验证方法，不要直接改；
- 只改与任务直接相关的文件，不改公共接口，不新增依赖；
- 完成后运行测试并做真实流程验证；
- 汇报时区分“已实际验证”和“未验证”，附命令或响应证据。
```
